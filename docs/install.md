# Как это встаёт в колонку

## 1. Собрать

```sh
scripts/build.sh          # docker, aarch64 + musl, статически
# → dist/zvukd, ~1,9 МБ
```

Отдельный Rust на маке не нужен — всё в контейнере. Цель выбрана по факту:
на колонке `uname -m` = `aarch64` и наши утилиты 64-битные, поэтому musl-static
избавляет от любых вопросов с glibc.

Скрипт собирает стадию `builder` и забирает бинарник из неё (`docker run … cat`):
финальная стадия — `FROM scratch`, у неё нет ни shell, ни команды, поэтому
`docker create` + `docker cp` на ней падают с «no command specified».

## 2. Поставить

```sh
STATION=<IP-КОЛОНКИ> scripts/install.sh
```

Скрипт идемпотентный. Что делает:

1. `/data/local/opt/zvuk/bin/zvukd` — бинарник;
2. `/data/local/etc/zvuk.token` — токен Звука, права `600` (берётся из
   `~/Cursor/zvuk-player/config.json`, если не задан `ZVUK_TOKEN`);
3. `/data/local/bin/zvukd` — обёртка, `/data/local/bin/zvukd-daemon.sh` — запуск с логом
   в `/data/local/tmp/zvukd.log`;
4. строка автозапуска в `/etc/init.d/S97station-root` (с проверкой, чтобы не дублировать);
5. запуск демона через `start-stop-daemon -b` — **обязательно так**: процесс,
   запущенный из SSH-сессии, умирает вместе с ней (проверено на `audio-owner.sh`).

**`scp` на колонке нет** (в dropbear его нет) — файлы кладутся через
`cat файл | ssh root@… 'cat > путь'`.

## Где живёт скачанный трек

Трек качается в `/tmp/zvukd` — это оперативная память (tmpfs), а не флеш: файл нужен
только на время воспроизведения, а `/data` на колонке всего 199 МБ и у него ограниченное
число перезаписей. Держатся два файла: текущий трек и предзагруженный следующий, остальные стираются.
Потолок одного файла 80 МБ — больше не качаем и отвечаем ошибкой. Путь переопределяется `ZVUKD_CACHE`,
например на флеш: `ZVUKD_CACHE=/data/local/tmp/zvukd`. После перезагрузки памяти «ничего
не остаётся» — для кэша это норма.

## 3. Проверить

```sh
ssh -i ~/.ssh/yandex_station -p 2222 root@<IP-КОЛОНКИ> \
  '/data/local/bin/zvukd ping && /data/local/bin/zvukd play "radiohead" && /data/local/bin/zvukd status'
```

Ожидаемо: `pong`, затем `Играет: Radiohead — ...`, затем `play|<трек>|<pid>`.

## 4. Токен

Токен — 32 символа веб-сессии Звука, тот же, что в конфиге Python-плеера. Живёт, пока
не вышел из аккаунта и не сменил пароль. Хранится только на колонке (`600`), в репозиторий
и в переписку не попадает.

Если токен протух — обновить файл и перезапустить:

```sh
scp токен root@…:/data/local/etc/zvuk.token
/data/local/bin/zvukd stop; start-stop-daemon -K -p /run/zvukd.pid; start-stop-daemon -S -b -m -p /run/zvukd.pid -x /data/local/opt/zvuk/bin/zvukd
```

## 5. Место и память

Для сравнения, на той же колонке: Python-вариант занял бы ~50 МБ на `/data` и 30–50 МБ RAM.
Статический Rust-бинарник — около 2 МБ на диске и ~10 МБ RAM. На момент установки свободно
на `/data` было 135 МБ (раздел всего 199 МБ), ОЗУ 500 МБ, из них около 290 свободно.
Треки на флеш не пишутся: они живут в `/tmp` (tmpfs, 245 МБ), поэтому запас `/data`
не тратится.

## 6. Удалить (если понадобится откат)

```sh
rm -f /data/local/opt/zvuk/bin/zvukd /data/local/bin/zvukd
# строку автозапуска из /etc/init.d/S97station-root убрать руками
```
